Some mobile file viewers show only a preview; open the file in a browser that supports local HTML.

Schedule convention: growing day 1 begins after the initial soak. Rinses are evenly spaced from that point (every 12 hours for twice daily or every 8 hours for three times daily). These clock times are a planning choice, not times specified by the PDFs. Dates use the viewing device’s local timezone; elapsed-hour spacing stays fixed across clock changes.

Harvest windows are estimates, not automatic readiness checks. Follow the listed size or leaf criteria. You can harvest early when ready; future rinses become inactive. If a batch needs longer, edit the plan before continuing; rebuilding a schedule clears that batch’s checkmarks.

Care instructions come from the four supplied PDFs. The broccoli PDF gives both 2–3 rinses daily and a twice-daily tip; the default is twice daily, with a three-rinse option. The optional customer tip about a 5–10 minute broccoli rinse soak is not included as a required step.
